# ProdActivity

## Who We Are

A small team of developers building productivity apps together. We work across the full stack, from React on the front to Node, Postgres, and a bit of Python behind it.

## Our Motivation

Most of us learned to code through coursework, where a project ends the day it's submitted. We wanted one that keeps going. Productivity is the theme because it's our own problem: classes, client work, and side projects all pile onto the same messy to-do list.

## Our Goal

To build apps people actually use, and to grow as engineers while doing it. Real code review, real deployments, real feedback. If it also makes a solid portfolio, good, but the work has to hold up first.
